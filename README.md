# Small-C and Micro-C

A  definition of a small C language, useful for teaching compiler design at the undergrad level, or for hobbyists.

There are two versions, they are mostly equivalent: the one I called Small-C, no relation to the famous book and implementation, and another called Micro-C.  The difference is mostly in the documentation I built to define them.

Live page: https://efutch.github.io/Small-C/
